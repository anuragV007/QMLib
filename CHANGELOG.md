# Changelog

## 0.4.0 — release candidate

- Added quantum-kernel ridge regression.
- Added quantum one-class SVM and quantum anomaly detector to the public model API.
- Added cached fidelity-kernel export.
- Generalized `QMLPipeline` to support regression and classification estimators.
- Standardized classifier/regressor compatibility with scikit-learn estimator conventions.
- Corrected the feature-map comparison example.
- Added regression and API-compatibility tests.
- Updated public documentation and quick-start examples.

This release remains PennyLane-based and does not claim provider-independent backend support or quantum advantage.
